# ドラクエ風RPG 開発プロンプト

以下のプロンプトを Claude Code にそのまま渡すことで、ブラウザで遊べるドラゴンクエスト風の2D RPGを実装できます。用途に応じて「フル版プロンプト」をベースに、末尾の「カスタマイズ用オプション」を追記・削除してください。

---

## フル版プロンプト（コピペ用）

```
ブラウザで動作するドラゴンクエスト風の2Dターン制RPGを作成してください。

# 全体方針
- 技術スタック: HTML5 Canvas + Vanilla JavaScript（ビルド不要。index.html を開くだけで動くこと）
- ファイル構成: index.html / src/ 以下に機能別のJSモジュール（ESM）/ assets/ 以下に必要なら画像
- グラフィックは外部画像に頼らず、Canvasへの矩形・ドット描画で自前生成してよい（16x16または32x32のタイルベース）
- 画面はレトロ調: 黒背景、白枠のメッセージウィンドウ、等幅フォント
- 対応環境: PC（キーボード）とスマホ（タッチ用の仮想十字キー＋決定/キャンセルボタン）
- 著作権対応: ドラゴンクエストの実在のモンスター名・呪文名・キャラクター・音楽・画像は使用しない。
  雰囲気だけ似せたオリジナルの名称・デザインにすること（例: スライム→「ぷにぷに」、ホイミ→「ヒール」等）

# ゲーム仕様

## 1. フィールド・マップ
- タイルマップ方式。最低3種類のマップを用意する:
  1. ワールドマップ（草原・森・山・海・毒沼。海と山は通行不可、毒沼は歩くとHP減少）
  2. 町（王城または民家・宿屋・武器屋・道具屋のあるマップ）
  3. ダンジョン（洞窟。最深部にボス）
- マップ間はワープタイル（町の入口、洞窟の入口、階段）で遷移する
- 主人公はグリッド単位で4方向移動。マップ端や通行不可タイルには進めない
- カメラは主人公中心にスクロール

## 2. 会話・イベント
- NPCを各マップに複数配置。話しかけるとメッセージウィンドウにテキストを1文字ずつ表示（決定キーで送り）
- 王様（またはそれに相当するNPC）からオープニングで使命を受ける導入イベント
- 宝箱: 開けるとゴールドまたはアイテム入手。開封済みフラグを保持
- 扉・カギなど簡単なフラグ管理を1つ以上入れる

## 3. 戦闘システム（ドラクエ1風の1対1でよい）
- フィールド・ダンジョン歩行中にランダムエンカウント（マップごとに出現テーブルと遭遇率を設定）
- 戦闘画面: 背景＋敵グラフィック＋コマンドウィンドウ＋メッセージウィンドウ
- コマンド: 「たたかう」「じゅもん」「どうぐ」「にげる」
- ダメージ計算: 攻撃力・守備力・乱数を使ったシンプルな式。会心の一撃（低確率で防御無視）とミスも実装
- 呪文: 攻撃呪文1種以上、回復呪文1種以上。MPを消費。レベルアップで習得
- 敵は3〜6種類＋ボス1体。敵ごとにHP/攻撃/守備/経験値/ゴールド/行動パターンを定義
- 「にげる」は確率で成功。ボス戦は逃走不可
- 勝利で経験値とゴールド獲得。敗北（HP0）で王城に戻され、所持金半分でHP全快（ゲームオーバーにしない）

## 4. 成長・アイテム
- ステータス: レベル / HP / MP / ちから / みのまもり / 経験値 / ゴールド
- 経験値テーブルによるレベルアップ（最大レベル10〜20程度）。レベルアップ時に能力上昇と呪文習得を表示
- 装備: 武器・防具 各3種類程度。武器屋で購入し、装備すると攻撃力・守備力に反映
- 道具: やくそう（HP回復）、毒消し等の消費アイテム。道具屋で購入、戦闘中・フィールド両方で使用可
- 宿屋: 宿泊するとHP/MP全快

## 5. メニュー・UI
- フィールドでメニューキーを押すと開くコマンドウィンドウ: 「つよさ」「じゅもん」「どうぐ」「そうび」「セーブ」
- ステータス画面で現在の能力値・装備・次のレベルまでの経験値を表示
- メッセージ・選択ウィンドウはすべて共通のウィンドウ描画関数で統一する

## 6. セーブ・ロード
- localStorage にセーブ（位置・ステータス・所持品・フラグ・ゴールドすべて）
- タイトル画面: 「はじめから」「つづきから」（セーブデータがある場合のみ選択可）

## 7. ゲームクリアまでの流れ（30分程度で1周できる規模）
1. 王様から「洞窟の魔物を倒し、奪われた宝を取り戻せ」という使命を受ける
2. 町で装備を整え、フィールドで戦ってレベル上げ
3. 洞窟最深部のボスを撃破し、宝を入手
4. 王様に報告してエンディング（スタッフロール的な一枚画面でよい）

## 8. 操作方法
- PC: 矢印キー移動 / Z or Enter = 決定・調べる・話す / X or Esc = キャンセル・メニュー
- スマホ: 画面下部に仮想十字キー、右下にA（決定）B（キャンセル）ボタン
- 操作方法はタイトル画面か README に明記する

# 品質要件
- グローバル変数を撒き散らさず、GameState / MapManager / BattleSystem / MessageWindow 等に役割分割する
- マップデータ・敵データ・アイテムデータはコードから分離した定義オブジェクト（data/ 配下等）にまとめ、追加しやすくする
- 60fps の requestAnimationFrame ループ。処理落ちしても移動速度が変わらない実装にする
- 完成後、ローカルで実際に起動して「移動→会話→戦闘→レベルアップ→買い物→セーブ→ロード→ボス撃破→クリア」まで一通り動作確認し、結果を報告する
```

## カスタマイズ用オプション（必要なものをフル版の末尾に追記）

### 規模を大きくしたい場合
```
- パーティ制（最大3人、戦士/魔法使い/僧侶）にし、戦闘は複数対複数にする
- マップを2つの町＋2つのダンジョンに拡張し、中ボスを追加する
- 船を入手すると海タイルを移動できるようにする
```

### 演出を強化したい場合
```
- Web Audio API でファミコン風のBGM（フィールド曲・戦闘曲・町の曲）と効果音を矩形波・三角波で自前生成する
- 戦闘時に画面フラッシュ・敵の点滅・シェイクなどの演出を入れる
- 昼夜の概念を入れ、夜はエンカウント率が上がる
```

### 規模を小さくしたい場合（まず動くものが欲しいとき）
```
- マップはワールドマップ1枚＋洞窟1つのみ、町の機能は王様の隣にNPCを置いて代替する
- 呪文・装備は各1種類、敵は2種類＋ボスのみでよい
- 1ファイル（index.html のみ）に全コードをまとめてよい
```

### デプロイまで任せたい場合
```
- 完成後、Vercel にデプロイして公開URLを報告してください
```

## このプロンプトの設計意図

| 項目 | 意図 |
|---|---|
| Canvas + Vanilla JS | ビルド環境不要で、生成されたコードがそのまま動く。依存トラブルが起きない |
| ドット絵の自前描画 | 画像アセットの用意・著作権問題を回避し、1回の指示で完結させる |
| 敗北してもゲームオーバーにしない | ドラクエの伝統仕様。バランス調整が甘くても詰まない |
| データとロジックの分離を明記 | 「敵を増やして」「マップを広げて」といった追加指示が通りやすくなる |
| 動作確認フローを明記 | 「作ったが動かない」を防ぎ、CLAUDE.md の報告フォーマットとも整合する |
| オリジナル名称の強制 | 実在のドラクエ用語・素材の流用による著作権リスクを避ける |
