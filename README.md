# ファイナルソード — ドラクエ風レトロRPG

HTML5 Canvas + Vanilla JavaScript で作られた、ブラウザで動くドラゴンクエスト風の2Dターン制RPGです。
ビルド不要・依存ライブラリなし。グラフィックはすべて Canvas によるドット絵の自前生成、
BGM・効果音も Web Audio API によるファミコン風サウンドの自前合成です（音源ファイルなし）。

## 遊び方（公開URL）

**https://game-self-xi.vercel.app** を開くだけでゲームが**自動スタート**します（PC・スマホ対応）。
タイトル表示の約1.5秒後に、セーブデータがあれば「つづきから」、なければ「はじめから」が自動で始まります。
やり直したいときは、ゲーム中メニュー（X/Bボタン）の「タイトルへ」からタイトルメニューに戻れます。

## ローカルでの起動方法

- `index.html` をブラウザで開くだけで動きます（ダブルクリックでOK）。
- ローカルサーバーを使う場合:

```bash
cd game
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

対応ブラウザ: Chrome / Safari / Firefox / Edge（PC・スマホ両対応）

## ゲームの流れ（クリアまで約30分）

1. **アルテア城** — 王様から「東の洞くつの魔物ドラゴネルを倒し、奪われた《ひかりのたから》を取り戻せ」という使命を受ける（支度金120G）
2. **城下町** — 武器屋・道具屋で装備を整え、宿屋（10G）で回復
3. **フィールド** — 戦ってレベル上げ。東の山に囲まれた洞くつへは**毒の沼**（歩くとHP減少）を越えて入る
4. **まかいの洞くつ B1** — 宝箱から**まほうのカギ**を入手（城の宝物庫の扉が開くようになる）
5. **洞くつ B2 最深部** — ボス「ドラゴネル」を撃破し《ひかりのたから》を奪還
6. **王様に報告** — エンディング

## 主なシステム

- **戦闘**: ランダムエンカウント、コマンド「たたかう / じゅもん / どうぐ / にげる」、会心の一撃・ミスあり。ボス戦は逃走不可
- **ラスボス**: 二段階進化。ドラゴネルを倒すと黒竜「真・ドラゴネル」に変身する
- **レア敵**: 銀色の「メタルぷに」(出現率約3〜4%)。超硬い・呪文無効・すぐ逃げるが、倒せば経験値150
- **成長**: 経験値でレベルアップ（最大Lv15）。**レベルアップ時はHP/MP全回復（毒も治る）**
- **呪文8種**（使用時に稲妻・炎・氷などのエフェクト演出つき）:
  | Lv | 呪文 | MP | 効果 |
  |---|---|---|---|
  | 3 | ヒール | 3 | HP回復 20-28 |
  | 5 | ファイア | 4 | 炎 15-24 |
  | 6 | まもり | 4 | 戦闘中しゅび力アップ |
  | 7 | スパーク | 7 | 雷 26-38 |
  | 8 | リターン | 8 | 城下町へ帰還（フィールド専用） |
  | 9 | ハイヒール | 8 | HP回復 58-75 |
  | 11 | ブリザド | 10 | 氷 44-62 |
  | 13 | インフェルノ | 14 | 大炎 68-95 |
- **装備**: 武器3種・防具3種。購入後メニューの「そうび」で装着
- **状態異常**: どく（歩くとHP減少。どくけしそう・宿屋で回復）
- **敗北**: 全滅してもゲームオーバーにならず、所持金半分で城に戻される
- **セーブ**: メニューの「セーブ」でいつでも記録（localStorage）。タイトルの「つづきから」で再開
- **サウンド**: 場面別BGM（タイトル/町/フィールド/洞窟/戦闘/エンディング）、
  戦闘効果音（攻撃・会心・被弾・呪文・回復・エンカウント・逃走）、勝利＆レベルアップのファンファーレ

## ファイル構成

```
index.html          エントリーポイント（タッチUI含む）
final-sword.html    全コード同梱の単一ファイル版（これ1つで動く）
src/main.js         起動処理
src/game.js         ゲーム本体（フィールド・イベント・メニュー）
src/battle.js       戦闘システム
src/audio.js        BGM・効果音・ファンファーレ（Web Audio APIで合成）
src/ui.js           ウィンドウ・メッセージ・選択メニュー
src/input.js        キーボード＆タッチ入力
src/sprites.js      タイル・キャラ・モンスターのドット絵生成
src/state.js        プレイヤー状態・セーブ/ロード
src/data/database.js  レベル・呪文・アイテム・装備・敵の定義
src/data/maps.js      マップ・NPC・宝箱・出現テーブルの定義
```

データ（マップ・敵・アイテム）はロジックから分離してあるので、
`src/data/` を編集するだけで敵やマップを追加できます。
